- **Skills you write for a kehikko reach Codex.** Every Codex session started on a kehikko now has the skills you wrote for it in its `$` menu, ahead of a module's skill with the same name, and is told what each is for.
- **Added while it runs.** A skill you add or change while a session is running is told to it at your next message, with how to read it; it is in the `$` menu from the session's next start.
- **Your own skills stay yours.** A skill of yours with the same name is never written over, and Codex sessions on other kehikkos have this kehikko's skills switched off.
