Kind: feature

- **Edits outside a worktree are refused** while Worktrees is on the kehikko: Codex's file edits in a project's main checkout, or in an installed module's folder, are stopped with how to make a worktree instead. Every command and file edit now goes through one shared guard check, so a new kind of guard a module declares is held here too. Codex reports its file edits to the check as patches; how firmly it holds them is up to Codex.

## For agents

- `apply_patch` goes through the same guard check as shell commands. When a module refuses a patch (for example Worktrees, a file in a main checkout), make a worktree as its reason says and apply the patch there.
