- **A skill Kehikot keeps for every conversation no longer goes stale when its module is removed or stopped.** Kept-everywhere skills are re-checked against their modules when this module starts and every few minutes while it runs: changed skill text is updated, and a skill whose module is no longer installed, or no longer offers it, is removed.
- **Session folders left behind by a stopped process are cleaned up at start.** A session folder naming a process that is no longer running — or naming none and over an hour old — is removed; the live folders of other running processes are left alone.
